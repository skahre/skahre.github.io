# skahre.github.io

Personal portfolio website built with React and TypeScript, showcasing projects and professional experience.

> **Note:** This project is still under active development and not yet complete.

**Live site:** [skahre.github.io](https://skahre.github.io)

## Tech Stack

- **React** + **TypeScript**
- **Vite**: build tool
- **React Router**: client-side routing
- **GitHub Pages**: hosting

## Features

- Responsive layout with mobile navigation menu

## Getting Started

```bash
npm install
npm run dev       # Start dev server at localhost:5173
npm run build     # Build for production
npm run preview   # Preview production build locally
```

## Deployment

The site deploys to GitHub Pages via the `gh-pages` package:

```bash
npm run deploy
```

This runs `build` and then pushes the `dist/` folder to the `gh-pages` branch.
